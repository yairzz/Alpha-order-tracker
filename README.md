# Alpha-order-tracker
מערכת פנימית למעקב אחר הזמנות פריטים לצוות Alpha Tau. **האפיון המלא והמעודכן נמצא ב-[SPEC.md](SPEC.md)**; כאן רק תקציר.

**כתובת:** https://yairzz.github.io/Alpha-order-tracker/ (ניתנת גם להתקנה כאפליקציה – PWA).

## טכנולוגיה
* קובץ `index.html` יחיד: React 18 (מתקמפל בדפדפן דרך Babel), Tailwind CSS, ללא Build Step. ממשק RTL בעברית.
* נתונים: Firebase Firestore (אוספים `orders`, `users`, `quoteFiles`, `settings`). הזדהות: Firebase Authentication (שם משתמש + סיסמה).
* ייצוא: `xlsx-js-style`, ו-`JSZip` כשיש הצעות מחיר.
* קבצי עזר ל-PWA בלבד: `manifest.webmanifest`, `sw.js`, `icons/`.
* אוטומציה: `automation/weekly-email.gs` (מייל בימי ראשון ורביעי) ו-`automation/gmail-cleanup.gs` (ניקוי שבועי), שני פרויקטי Google Apps Script נפרדים.

## יכולות עיקריות
* כניסה עם שם משתמש וסיסמה; ניהול משתמשים בידי המנהל; החלפת סיסמה חובה בכניסה הראשונה.
* הוספה ועריכה של הזמנות, שינוי סטטוס מהטבלה, הערות ומספר מעקב, חיפוש וסינון לפי פרויקט.
* צירוף עד 2 הצעות מחיר (PDF או XLSX, עד 700KB) לכל הזמנה.
* סימון "אומתה ונסגרה" מעביר את ההזמנה לארכיון אוטומטית, עם הודעה וכפתור "בטל".
* ייצוא לאקסל; כשיש הצעות מחיר – קובץ ZIP עם האקסל והקבצים.
* מייל אוטומטי לשגיא (ראשון ורביעי) עם האקסל והצעות המחיר של הפריטים בסטטוס "ראשוני" ו"נשלחה לשגיא", דרך ממסר Outlook (Power Automate). פריט ממשיך להישלח עד ששגיא מעביר אותו הלאה. למנהל יש גם כפתור "שלח עכשיו".

## סטטוסים
`ראשוני` ← `נשלחה לשגיא` ← `נשלחה למחלקת רכש` ← `אושרה ע"י אלירן` ← `הוזמנה` ← `התקבלה במחלקת רכש` ← `נמסרה` ← `אומתה ונסגרה` (← ארכיון).
סטטוסי חריגה: `הגיע שגוי/תקול`, `התקבל חלקית`, `הוזמן מחדש`.

## כללים קשיחים לפיתוח
* קובץ HTML יחיד ללא Build Step. כל הלוגיקה ב-`index.html`.
* ייצוא לאקסל: **בדיוק 5 עמודות** – `שם הפריט`, `כמות`, `פרויקט`, `קישור`, `הערות`. **בלי** עמודת מזמין. הצעות המחיר נוספות כקבצים נפרדים ב-ZIP, לא כעמודה.
* הריפו ציבורי: אסור לשמור בו סיסמאות, קודים סודיים או רשימות משתמשים. ההגנה האמיתית היא Firestore Security Rules (מתועדים ב-SPEC).
* כל שינוי פונקציונלי מתעדכן ב-SPEC.md.
