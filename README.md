# Alpha-order-tracker
טקסט זה מרכז את ההקשר הארכיטקטוני והפונקציונלי של מערכת מעקב ההזמנות, ומוכן להעתקה לתחילת השיחה החדשה יחד עם קוד ה-HTML המעודכן.

**הגדרת המערכת והטכנולוגיה**

* **מהות האפליקציה:** אפליקציית Web בעמוד יחיד (Single File SPA) לניהול, מעקב וסנכרון דרישות רכש והזמנות ציוד עבור צוותים.
* **סטאק טכנולוגי:** React 18 (הורצה בדפדפן דרך Babel), Tailwind CSS לעיצוב רספונסיבי, Firebase Firestore (Compat SDK v10.8.0), וספריית `xlsx-js-style` להפקת דוחות Excel מעוצבים.
* **ניהול נתונים דואלי (Dual Storage):** סנכרון בזמן אמת מול מסד הנתונים Firebase Firestore (קולקציית `orders`). במקרה של ניתוק, שגיאת רשת או מחסור בהגדרות, המערכת עוברת אוטומטית לעבודה מול `localStorage` מקומי.

**מבנה הנתונים ומודל העבודה**

* **שדות פריט:** שם הפריט (`itemName`), מזמין (`requestedBy`), מספר הזמנה (`orderNumber`), מספר מעקב (`trackingNumber`), כמות (`quantity`), פרויקט (`project`), קישור לאתר (`url`), סטטוס (`status`), הערות (`notes`), תאריך יצירה, וסימון ארכיון (`isArchived`).
* **תהליך עבודה (Status Workflow):** `ראשוני` ⬅️ `נשלחה לשגיא` ⬅️ `נשלחה למחלקת רכש` ⬅️ `אושרה ע"י אלירן` ⬅️ `הוזמנה` ⬅️ `התקבלה במחלקת רכש` ⬅️ `נמסרה` ⬅️ `אומתה ונסגרה`.

**יכולות מרכזיות וממשק משתמש**

* **דאשבורד וסינון:** כרטיסיות מדדים (סה"כ פעילות, בתהליך, הושלמו, בארכיון), חיפוש חופשי, וסינון לפי פרויקט מתוך רשימה הנגזרת דינמית מהנתונים.
* **טבלה ומיון:** מיון דינמי לפי עמודות, בחירת שורות מרובה (Checkbox), מודאליות מהירות לעריכת הערות ומספר מעקב, והשלמה אוטומטית (`datalist`) לשדות פרויקט ומזמין.
* **ייצוא לאקסל (`XLSX`):** ייצוא מותאם RTL הכולל עיצוב כותרות וקישורים לחיצים פעילים.
* **כלל ייצוא קשיח (הנחיה מיוחדת):** דוח האקסל כולל **5 עמודות בלבד**: `שם הפריט`, `כמות`, `פרויקט`, `קישור`, `הערות`. עמודת ה"מזמין" ושדות נוספים מוחרגים במפורש מדוח האקסל.

**הנחיות להמשך פיתוח בשיחה החדשה**

* יש לשמור על הארכיטקטורה של קובץ HTML יחיד ללא תהליך בילד (Build Step).
* כל שינוי בפונקציית הייצוא לאקסל חייב להישמע לכלל 5 העמודות ללא עמודת מזמין.
* שמירה על תמיכה מלאה ב-RTL, ממשק נקי, וסנכרון דו-כיווני (Firebase + LocalStorage).
